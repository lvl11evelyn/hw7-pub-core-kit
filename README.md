# HW1 Public Core Kit

Public distribution repository for the HW1 Core Kit, a unified HoboWars userscript suite providing stat tracking, trade and Jungle telemetry, combat-roll calculations, interface panels, keyboard shortcuts, and local import/export tools.

## Included modules

- Combat Roll Ranges
- Jungle Berry Event Tracker
- Mines Telemetry Tracker
- Topbar Total Battle Stats
- Mining Log

## Installation

1. Install Tampermonkey or another compatible userscript manager.
2. Open the raw `HW7 Public Core Kit.user.js` file from this repository.
3. Confirm the installation prompt.

## Data and permissions

HW1 Core Kit processes HoboWars page content locally.

It stores tracker records through Tampermonkey storage and browser storage, supports user-initiated text import and export.

This userscript **does not transmit any of its stored data.**

## Compatibility

Designed for HoboWars 1 on personal computers and currently supports only the in-game **The Future** layout.

The suite was developed and tested on Windows using Mozilla Firefox. Compatibility with other operating systems and browsers has not been tested. Interface geometry may also vary with browser viewport, zoom, display scaling, and available fonts.
